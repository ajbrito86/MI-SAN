# Mi-San - Visión General

## Descripción

Mi-San es una aplicación móvil que permite administrar, organizar y dar seguimiento a sociedades de ahorro tradicionales (San, Sociedad, Junta, Tanda).

La aplicación NO custodiará dinero ni realizará movimientos financieros en el MVP.

Su propósito inicial es sustituir el cuaderno, grupos de WhatsApp y hojas de Excel utilizados actualmente para administrar sociedades.

## Objetivos del MVP

- Digitalizar la gestión de sociedades.
- Llevar historial de pagos y cobros.
- Registrar participantes.
- Gestionar turnos.
- Permitir evidencias de pago.
- Notificar vencimientos.
- Identificar participantes morosos.
- Facilitar el trabajo del organizador.

## Roles

### Organizador

Persona responsable de administrar la sociedad.

Puede:

- Crear sociedades.
- Invitar participantes.
- Configurar turnos.
- Confirmar pagos.
- Gestionar morosidad.
- Crear nuevos ciclos.
- Ver reportes.

### Participante

Persona invitada a una sociedad.

Puede:

- Ver turnos.
- Ver historial.
- Reportar pagos.
- Enviar comprobantes.
- Recibir notificaciones.

## Principios del MVP

- Simplicidad.
- Transparencia.
- Confianza.
- Experiencia mobile first.
- Bajo nivel de fricción.
- Adaptado a la cultura dominicana.
