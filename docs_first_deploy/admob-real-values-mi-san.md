# AdMob Real Values MI-SAN

Valores pendientes para reemplazar los IDs de prueba cuando MI-SAN exista como app dentro de Google AdMob.

| Valor | Estado | Fuente | Donde se configura |
|---|---|---|---|
| ADMOB_ANDROID_APP_ID | Pendiente | AdMob | env |
| ADMOB_ANDROID_BANNER_ID | Pendiente | AdMob | env |
| ADMOB_ANDROID_INTERSTITIAL_ID | Pendiente | AdMob | env |
| ADMOB_IOS_APP_ID | Pendiente | AdMob | env |
| ADMOB_IOS_BANNER_ID | Pendiente | AdMob | env |
| ADMOB_IOS_INTERSTITIAL_ID | Pendiente | AdMob | env |

Publisher ID disponible: `pub-8890665262846106`.

Hasta crear la app MI-SAN en AdMob, el proyecto conserva IDs oficiales de prueba en desarrollo. En produccion el preflight emite avisos si detecta placeholders o test IDs; mas adelante esos avisos pueden elevarse a errores.
