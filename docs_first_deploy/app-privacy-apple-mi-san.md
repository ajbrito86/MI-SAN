# App Privacy Apple MI-SAN

## Categorias De Datos

### Contact Info

Datos:

- Name.
- Email Address.
- Phone Number.

Proposito:

- App Functionality.
- Customer Support.

Vinculado al usuario:

- Si.

Usado para tracking:

- No, salvo identificadores publicitarios administrados por consentimiento de Ads.

### User Content

Datos:

- Fotos opcionales.
- Evidencias/comprobantes cargados por el usuario.
- Contenido operativo de SANes.

Proposito:

- App Functionality.

Vinculado al usuario:

- Si.

### Identifiers

Datos:

- User ID interno.
- Device/Advertising ID cuando aplique por AdMob y consentimiento.

Proposito:

- App Functionality.
- Advertising.
- Analytics.

Vinculado al usuario:

- Si.

Tracking:

- Puede aplicar para publicidad personalizada cuando el usuario otorga consentimiento.

### Usage Data

Datos:

- Product Interaction.
- Eventos de monetizacion.
- Eventos de anuncios.

Proposito:

- Analytics.
- App Functionality.
- Advertising.

Vinculado al usuario:

- Si.

### Diagnostics

Datos:

- Crash Data.
- Performance Data.

Proposito:

- Analytics.
- App Functionality.

Vinculado al usuario:

- Puede vincularse a la cuenta para soporte y depuracion.

## Data Linked To User

- Contact Info.
- User Content.
- Identifiers.
- Usage Data.
- Diagnostics.

## Tracking

MI-SAN puede usar identificadores para anuncios personalizados mediante AdMob cuando el usuario otorga consentimiento.

Texto configurado en iOS:

`MI-SAN usa identificadores para mostrar anuncios personalizados cuando das tu consentimiento.`

## Account Deletion

La app permite eliminar cuenta desde:

Perfil -> Cuenta -> Eliminar cuenta.

El flujo requiere:

- Contrasena actual.
- Confirmacion escribiendo `ELIMINAR`.

## In-App Purchase

Producto sugerido:

- Tipo: Non-Consumable.
- Product ID: `premium_sin_ads`.
- Precio inicial: US$4.99.
- Beneficio: Premium sin anuncios.
